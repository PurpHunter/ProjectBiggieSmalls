==============================
Federated AI Environment Setup
==============================

This guide will help you set up the Python environment and run the Federated AI system, including servers and device clients.

--------------------------------------
1. Install Anaconda (if not installed)
--------------------------------------
1. Download Anaconda for your OS from:
   https://www.anaconda.com/products/distribution

2. Install Anaconda following default options.

3. After installation, open "Anaconda Prompt" or your terminal.

--------------------------------------
2. Clone / Download the Project
--------------------------------------
1. Place the project folder somewhere convenient, e.g.:
   C:\Users\YourName\Documents\AI_Development

2. Your folder structure should look like:

AI_Development\
├── central_server\
├── devices\
│   ├── device_A\
│   ├── device_B\
│   └── device_C\
├── models\
│   ├── global_vectorizer.joblib
│   └── mental_health_classifier.joblib
└── scripts / other files

--------------------------------------
3. Create Python Environment
--------------------------------------
1. Open Anaconda Prompt.
2. Navigate to the project folder:
   cd C:\Users\YourName\Documents\AI_Development
3. Create the environment:

   conda create -n federated-ai python=3.11 -y

4. Activate the environment:

   conda activate federated-ai

5. Install dependencies:
   pip install -r requirements.txt
   pip install flask pandas scikit-learn joblib requests numpy

--------------------------------------
4. Organize CSV Data
--------------------------------------
1. Each device has its own CSV for training:

   devices\device_A\crew_A_train.csv
   devices\device_B\crew_B_train.csv
   devices\device_C\crew_C_train.csv

2. The validation CSVs are optional (for testing/evaluation):

   devices\device_A\crew_A_val.csv
   devices\device_B\crew_B_val.csv
   devices\device_C\crew_C_val.csv

3. Place the global vectorizer in each device folder (or central models folder):

   devices\device_A\global_vectorizer.joblib
   devices\device_B\global_vectorizer.joblib
   devices\device_C\global_vectorizer.joblib

--------------------------------------
5. Running the Servers
--------------------------------------
1. Activate the environment:
   conda activate federated-ai

2. Start each server in a separate terminal:

   a) Auth server (handles login):
      python central_server\auth_server.py

   b) Federated server (aggregates models):
      python central_server\federated_server.py

   c) AI server (handles chat and agents):
      python central_server\ai_server.py

--------------------------------------
6. Running Device Clients
--------------------------------------
1. Open a new terminal for each device.
2. Activate the environment:
   conda activate federated-ai
3. Navigate to the device folder, e.g.:

   cd devices\device_A

4. Run the federated client:

   python federated_client.py

5. Repeat for devices B and C.

--------------------------------------
7. Notes / Tips
--------------------------------------
- Ensure the CSV files are in the **same folder as the device client script**.
- Make sure the global vectorizer is also in the device folder.
- The first device can bootstrap the global model if none exists.
- Local accuracy may vary depending on the dataset size and quality.
- If using Windows, you can optionally create a `.bat` file to launch all servers and devices.
- For front-end integration:
   - Front-end connects to Auth server for login.
   - Front-end connects to AI server for chat.
   - Federated server communicates only with devices internally.

--------------------------------------
8. Troubleshooting
--------------------------------------
- If you get a "CSV not found" error:
  Check that the CSV file is in the **same folder** as the script.
- If the client fails due to vectorizer:
  Ensure `global_vectorizer.joblib` is present in the same folder.
- If local_accuracy is very low:
  Consider using **larger datasets** or improving preprocessing.

--------------------------------------
9. Optional
--------------------------------------
- Use the provided `generate_crew_data.py` script to create synthetic datasets for devices A, B, and C.
- Ensure that you do not overwrite existing CSVs unless you intend to regenerate training data.

End of Instructions
